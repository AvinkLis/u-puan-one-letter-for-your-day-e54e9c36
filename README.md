Entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

The program (`main.ts`, Node 22, standard library only) writes exactly one
letter — a single character, A to Z, with nothing else, no punctuation and
no trailing newline — to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `/output` by default). That one letter stands
for the word that describes the day; choosing the letter whose hidden word
feels most vivid, funny and true is the whole entry.

Run it with:

```sh
node main.ts
```
